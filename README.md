# VIEWE-DesKnob
VIEWE-DesKnob is a high-performance AI smart knob display module in the VIEWE housed finished-goods series. It is based on the Espressif ESP32-S31NRV16 SoC (QFN80, 16 MB  PSRAM; on-board external W25Q128 Flash) and a 2.1-inch round capacitive touch panel (resolution 360×360, display driver IC GC9B72NA, touch IC CST826, host-side QSPI interface).
